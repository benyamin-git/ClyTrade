# میانگین ورود / DCA

## به چه کار می‌آید

پوزیشن فعلی را با یک پر شدن جدید ترکیب می‌کند و میانگین قیمت ورود حاصل،
سایز کل و میزان جابه‌جایی میانگین نسبت به ورود قبلی را نشان می‌دهد.

## نحوهٔ استفاده

1. **سایز فعلی** و **قیمت ورود فعلی** را وارد کنید (برای ورود تازه، سایز را 0
   بگذارید).
2. **سایز افزودن** و **قیمت افزودن** را وارد کنید.
3. میانگین ورود جدید و درصد تغییر را در بخش نتایج بخوانید.

## چرا این‌طور کار می‌کند

- **میانگین‌ها مجانی نیستند.** پایین آوردن میانگین با افزودن بزرگ‌تر، پوزیشن و
  ریسک کل را افزایش می‌دهد. ارزش پوزیشن کل و سایز کل همیشه کنار میانگین نشان
  داده می‌شوند تا معامله در دید بماند.
- **سایز فعلی صفر هم مجاز است.** همین ماشین‌حساب ورودهای نخست و افزودن‌های
  DCA را پوشش می‌دهد.
- **درصد تغییر علامت‌دار است.** عدد منفی یعنی میانگین بهتر شده است (برای
  لانگ). این یک واقعیت است، نه توصیه.

## فرمول

```
totalNotional     = existingSize × existingEntry + addSize × addPrice
averageEntryPrice = totalNotional / (existingSize + addSize)
priceChangePercent = (averageEntryPrice / existingEntry − 1) × 100
```

## فرض‌ها

- `addSize` باید بزرگ‌تر از صفر باشد.
- کارمزد لحاظ نمی‌شود.
- بدون اهرم: اینجا فقط قیمت ترکیبی دارایی پایه مدل‌سازی می‌شود.
