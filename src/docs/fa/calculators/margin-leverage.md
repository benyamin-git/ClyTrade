# مارجین و اهرم

## به چه کار می‌آید

نشان می‌دهد باز کردن یک پوزیشن چقدر هزینه دارد: مارجین لازم، سهمی از حساب که
قفل می‌شود، قدرت خرید با اهرم شما، و حرکت مخالفی که بافر مارجین را مصرف می‌کند.

## نحوهٔ استفاده

1. **حجم سرمایه** و **ارزش پوزیشن** موردنظر برای معامله را وارد کنید.
2. **اهرم** را تنظیم کنید.
3. **مارجین نگهداری** را تنظیم کنید (0.5% نقطهٔ شروع رایجی است؛ صرافی خود را
   بررسی کنید).
4. مارجین لازم، میزان مصرف مارجین، حداکثر ارزش پوزیشن و اهرم مؤثر را بخوانید.

## چرا این‌طور کار می‌کند

- **اهرم مؤثر عدد صادقانه است.** پوزیشن 5,000 روی حساب 1,000، صرف‌نظر از تنظیم
  10x، اهرم مؤثر 5x است. ماشین‌حساب هر دو را نشان می‌دهد تا همیشه بدانید
  واقعاً با کدام‌یک کار می‌کنید.
- **میزان مصرف مارجین درصدی از حساب است.** هر مقدار بالای 100% یعنی با آن
  اهرم نمی‌توانید پوزیشن را باز کنید.
- **حرکت تا لیکویید شدن ابزاری برای برنامه‌ریزی است.** فاصله تا درد است، نه
  قیمت اعلامی دقیق صرافی.

## فرمول

```
requiredMargin         = positionNotional / leverage
marginPercentOfAccount = requiredMargin / accountSize × 100
maxPositionNotional    = accountSize × leverage
effectiveLeverage      = positionNotional / accountSize
liquidationMovePercent = 100 / leverage − maintenanceMarginPercent
```

## فرض‌ها

- مارجین ایزوله، بدون سود و زیان تحقق‌نیافته، بدون پرداخت فاندینگ.
- کل مارجین اولیه برای پوزیشن واریز می‌شود.
